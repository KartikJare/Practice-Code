# 💻 Practice Code – Multi-Language Concepts

## 📌 Description

This repository contains simple programs written in **C, C++, and Java** to demonstrate and compare **basic programming concepts across different languages**.

The purpose of this project is to understand how the same logic or concept is implemented in multiple programming languages.

---

## 🎯 Objective

* Learn core programming concepts
* Compare syntax and behavior across languages
* Understand differences between:

  * Procedural (C)
  * Object-Oriented (C++, Java)
* Build a strong foundation in multiple languages

---

## 🚀 Features

* 🔁 Same concept implemented in:

  * C
  * C++
  * Java
* 🧠 Focus on fundamental concepts (not complexity)
* 📚 Easy-to-understand and beginner-friendly code

## 🧑‍💻 How to Run

### ▶️ C

```bash
gcc program.c -o output
./output
```

### ▶️ C++

```bash
g++ program.cpp -o output
./output
```

### ▶️ Java

```bash
javac Program.java
java Program
```
